# Гра по мережі через HOME GAME SERVER (HGS)

Основний спосіб мережевої гри. Друзі відкривають https://idologonia.github.io/WarFare/ → **Гра по мережі**,
першого разу реєструються (ім'я + пароль) — і грають. Сервер — HGS на вашому ПК.

## Один раз на ПК з HGS

1. Має бути встановлений **Node.js** (https://nodejs.org) — ним HGS-логіка WarFare рахує правила бою.
2. Репозиторій адреси `idologonia/hgs-address` і тунель — як в інструкції HGS (`docs/guides/add-new-game.md`).
3. Скачайте WarFare: **Code → Download ZIP**, розпакуйте.
4. HGS → **Games → + Додати гру** → виберіть папку WarFare → **Start**.

Після оновлення гри: HGS → картка WarFare → **Stop**, замініть папку свіжим ZIP, **Start**.

## Як це працює

* `public/hgs.js` — SDK HGS (копія `sdk/js/hgs.js`), підключений у `index.html`.
* `hgs-game.json` — опис гри для HGS (`id: warfare`, вхід за акаунтом, серверна логіка).
* `server/logic.py` — серверна логіка (`hgs_sdk.GameLogic`): кімнати на двох, сторони, черга ходів.
  Кожну дію гравця перевіряє й застосовує `server/sim-node.cjs` — ті самі правила бою, що й у грі
  (збираються командою `npm run build:hgs` з `server/sim-entry.ts`). Сервер — головний.
* Клієнт (`src/net/hgsClient.ts`, `src/ui/hgsMenu.ts`) надсилає лише дії (`wf_action`); від сервера —
  `wf_start` (сценарій і seed), `wf_applied` (дії суперника), `wf_state` (повний стан при розбіжності
  чи поверненні в кімнату), `wf_peer` (суперник від'єднався/повернувся).
* Якщо HGS вимкнено — одиночна гра, гра вдвох на одному пристрої й тестовий режим працюють як завжди.

Перевірка на своєму ПК без тунелю: відкрийте гру з `?hgs=ws://127.0.0.1:8765` в кінці адреси.

## Резервний сервер

Попередній власний сервер (`start-server.bat`, `server/index.ts`, `docs/ONLINE.md`) лишився як запасний:
«Гра по мережі» → **Резервний сервер**.

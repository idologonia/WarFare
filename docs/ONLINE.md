# Гра по мережі (сервер на вашому ПК)

Сервер працює на вашому комп'ютері з Windows. Другий гравець нічого не встановлює: він просто відкриває посилання в браузері.

## Один раз: підготовка

1. Встановіть **Node.js LTS**: https://nodejs.org (кнопка LTS, далі «Next» до кінця).
2. Встановіть **cloudflared** (безкоштовний тунель Cloudflare, реєстрація не потрібна). Відкрийте «Командний рядок» і виконайте:
   ```
   winget install --id Cloudflare.cloudflared
   ```
3. Завантажте гру: на GitHub натисніть **Code → Download ZIP** і розпакуйте (або `git clone`).

## Щоразу, коли хочете грати

1. Двічі клацніть **start-server.bat** у папці гри. Перший запуск триває кілька хвилин (завантаження й збірка).
2. Відкриється вікно сервера, а в основному вікні з'явиться рядок з адресою виду `https://щось-там.trycloudflare.com`.
3. Надішліть цю адресу другому гравцю. Самі відкрийте її (або http://localhost:8080) у браузері.
4. **Гра по мережі** → створіть кімнату (сценарій, сторона, складність). Другий гравець відкриває адресу, натискає **Гра по мережі** і бачить вашу кімнату в списку.

Не закривайте обидва чорні вікна, поки граєте.

## Важливо

- Адреса `trycloudflare.com` змінюється при кожному запуску. Постійна адреса можлива, якщо прив'язати свій домен до Cloudflare (кілька доларів на рік) — скажіть, налаштуємо.
- Гру з GitHub Pages теж можна під'єднати до вашого сервера: у «Гра по мережі» вставте адресу сервера в поле «Адреса сервера».
- Індикатор у меню показує, чи сервер онлайн.
- Якщо гравець випав — бій лишається на сервері; повернення в бій після обриву буде додано наступним кроком.

## Як це працює

Сервер роздає гру й тримає кімнати. Обидва клієнти й сервер рахують бій однаково (детермінована симуляція з однаковим seed). Кожну команду гравця сервер перевіряє: ходити можна лише своєю стороною і лише у свій хід. Якщо стан розійшовся, сервер надсилає повний стан для синхронізації.

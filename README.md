# WarFare

Ізометрична тактична покрокова гра для браузера (ПК і телефони). TypeScript + Babylon.js.
Перша поставка — одна повна місія «Зачистка хутора» з умовною тестовою фракцією.

## Запуск

```bash
npm install
npm run dev        # розробка: http://localhost:5173
npm run build      # збірка в dist/ (статичні файли, можна розмістити на будь-якому хостингу)
npm run preview    # перегляд збірки
npm test           # unit- та integration-тести
```

Після першого відкриття збірки гра працює офлайн (service worker кешує ресурси й підтягує оновлення, коли є мережа).

## Контент

- Зброя (умовні ігрові характеристики): АК-74, АКМ, АК-200, АК-12, AR-15, ПКМ, Minimi; гранати РГД-5 і Ф-1.
- Магазини з частковою сумісністю: магазин РПК на 45 підходить до АК-74/АК-12/АК-200, Minimi бере короб і магазини STANAG.
- Модифікації (лише перед місією, екран «Підготовка» → «Спорядження»): планка Пікатінні, коліматор, магніфер, приціл 4х, ручка перенесення вогню. Підствольний модуль — разом із гранатометами.
- Медицина за MARCH: тампонада — лише рани кінцівок; турнікет можна накласти собі; оклюзійну наліпку й декомпресійну голку — лише інший боєць.

## Редактори і тестовий режим

- **Редактор карт** (головне меню): місцевість, стіни, вікна, двері, укриття, рослинність, підлога верхніх поверхів, сходи, пагорби, «випадковий об’єкт» (процедурна варіація при кожному старті місії). Пензель 1×1–3×3 або прямокутник, Ctrl+Z, зміна розміру, експорт/імпорт файлом. Будівлі (для прозорих стін) визначаються автоматично.
- **Редактор сценаріїв**: назва, брифінг, тип, карта, час доби, погода, рівень AI, ліміт ходів, затримка підкріплення, випадкові події, видимість карти; для кожної сторони — керування (гравець/AI), стиль AI, склад за класами, спорядження (± запасні магазини, гранати, без броні); зони розгортання й евакуації малюються на міні-карті. Експорт сценарію разом із картою для поширення.
- **Тестовий режим** («Тест: обидві сторони» → кнопка «Пісочниця»): додати бійця будь-якої сторони й класу в будь-яку клітинку, перенести, прибрати, видати зброю, вилікувати, поранити, поповнити AP і БК.

Користувацькі карти й сценарії зберігаються в браузері (localStorage) і з’являються у списку «Нова місія».

## Архітектура

```
src/
  app/          запуск і життєвий цикл (меню → підготовка → бій → результати)
  core/         seed-випадковість, сітка, версії
  content/      JSON: правила балансу (rules.json), предмети, класи, імена, карта, сценарій
  game/
    simulation/ стан місії, команди з валідацією, фази ходу
    combat/     рух, AP, стрільба, укриття, шанс влучання, гранати, overwatch
    units/      генерація бійців, похідні показники (AP, вага, огляд)
    injuries/   травми частин тіла, кровотечі, медицина
    inventory/  слоти, підсумки, рюкзак із клітинками, магазини
    visibility/ лінія огляду, виявлення/ідентифікація
    maps/       карта, поверхи, пошук шляху
    ai/         тактичний AI
    scenarios/  результати місії
    vehicles/ drones/ logistics/ equipment/  заготовки моделей даних для наступних етапів
  rendering/    Babylon.js: сцена, камера, моделі, ефекти (лише відображає стан)
  ui/           екрани й панелі (DOM поверх сцени), налаштування, музика
  persistence/  IndexedDB-слоти, автозбереження, експорт/імпорт, міграції
  networking/   (етап 6)
tests/          тести правил і повної місії
```

Принципи: симуляція не залежить від рендерингу й UI. Стан змінюється тільки командами (`game/simulation/commands.ts`); ті самі команди використовує AI, а пізніше — мережа. Стан місії — звичайний JSON із `schemaVersion`; випадковість задається seed і зберігається разом зі станом.

Баланс (AP, вартість дій, формули влучання, шкоди, броні, кровотеч, моралі) лежить у `src/content/rules.json` і редагується без зміни коду.
